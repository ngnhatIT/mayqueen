# Mayqueen website mock

Homepage mock for mayqueen.vn (Mayqueen Slim and Yodetox), built with the taste-skill design workflow.

- `mock/` – current version (v3): full-width commerce layout, 3D bottle hero (three.js), product grid filtered by need, one scroll scene.
- `mock/v2/`, `mock/v1/` – earlier directions, kept for comparison.
- `.taste-skill/notes.md` – direction, idea, critique rounds.

Open `mock/index.html` through a local server (`python -m http.server --directory mock`).
If the device has reduced motion turned on, add `?motion=on` to see the motion.

Prices, ingredients, legal numbers and the review are sample content. Photographs come from Wikimedia Commons (credits in the page footer); the bottles are 3D renders standing in for product photography.
